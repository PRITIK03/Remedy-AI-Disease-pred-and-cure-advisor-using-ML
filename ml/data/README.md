# Dataset: heart.csv

## Identity

- **File:** `ml/data/heart.csv` — 303 rows × 14 columns (13 features + `target`)
- **Downloaded from:** `https://raw.githubusercontent.com/kb22/Heart-Disease-Prediction/master/dataset.csv`
- **Original (legacy training) source:** Kaggle `ronitf/heart-disease-uci`
  ("Heart Disease UCI"), the famous mislabeled Kaggle mirror of the UCI
  Cleveland heart dataset.
- **SHA-256:** recorded in `dataset_meta.json` (generated by
  `scripts/download_dataset.py`; verified by `scripts/verify_dataset.py`).

## Why this is the EXACT legacy training dataset

Phase 0 recorded the legacy `scaler.pkl` `mean_`/`scale_` vectors. This file
reproduces **all 13 feature means and standard deviations to 4 decimal
places**. Additionally, a LogisticRegression trained on this file reproduces
the legacy model's coefficient **signs on all 13 features**, and the legacy
scaler+LR pair reproduces ~85.8% accuracy on the full data with the *correct*
target pairing (class 0 of the legacy model = disease). See
`docs/legacy-ml-baseline.md` §1 and `docs/ml-modernization-results.md`.

## ⚠️ Target semantics — read before use

This dataset's `target` column is **inverted relative to clinical intuition**
(a widely documented problem of the Kaggle `ronitf/heart-disease-uci` file;
in the original UCI Cleveland data, higher target values meant *more* disease):

- `target = 1` → **LESS chance of heart attack** (no disease)
- `target = 0` → **MORE chance of heart attack** (disease present)

Evidence: in this data, higher `ca`/`oldpeak`/`exang`/`thal` (strong disease
markers) associate with `target = 0`; higher `thalach` (fitness) associates
with `target = 1`. The legacy models were trained with this encoding as-is
(verified by coefficient-sign reproduction), and the legacy app then read
`predict_proba()[:, 1]` as "disease risk" — publishing P(healthy) as risk.
See `docs/legacy-ml-baseline.md` §6.

**The modern pipeline therefore flips the target during training:**
`y_disease = 1 - target`, giving `1 = disease, 0 = no disease`.

## Licensing / redistribution

The underlying UCI Heart Disease dataset has been redistributed publicly for
decades (UCI, Kaggle, countless GitHub mirrors and papers). No patient PII is
present (anonymized 1990s-era research features). Committed here for
reproducibility with provenance above; delete `heart.csv` and re-run
`scripts/download_dataset.py` if you prefer not to vendor it.

## Regeneration

